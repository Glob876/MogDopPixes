# MogDopPixes

Текущий этап — рабочий редактор, веб-версия, публичный репозиторий и релизы.
Пользователь разрешил реализацию, публикацию в GitHub и Cloudflare Pages,
а также интеграцию в MogDopTeam.

- Общаться и писать документацию на русском; Rust API — на английском.
- Внешний вид согласован: цвета MogDopTeam, квадратные панели, пиксельные иконки,
  инструменты слева, холст в центре, палитра и слои справа, кадры снизу.
- В телефонном режиме инструменты снизу; палитра, слои и кадры открываются
  отдельными панелями. Поддерживать узкие портретные окна Electron.
- Светлая и тёмная темы; без неона, градиентных украшений и сетевых шрифтов.
- Не оставлять фиктивных команд: функции должны работать или явно обозначать ограничение.
- Сохранять несвязанные пользовательские изменения MogDopTeam.
- Разработка в dev; владелец публичного репозитория — Glob876.
- Проверка перед сдачей: `npm run build`, осмотр широкого и узкого окна.
